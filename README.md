# 다각형의 내각, 외각의 크기의 합 — Vercel + Supabase 버전 2

## 바뀐 활동
1. 사각형·오각형·육각형에서 학생이 출발 꼭짓점을 직접 정하고 대각선을 그어 삼각형 수와 내각의 합을 찾기
2. 내각 개념 적용 문제
3. 사각형·오각형의 모양을 바꾸고 연장선/외각을 선택해 한 점 둘레에 모아 360° 확인
4. 내각+외각=180°n을 이용한 외각 합 360° 설명 및 드래그앤드롭 식 완성
5. 외각 개념 적용 문제
6. 정다각형 한 내각·한 외각 공식 드래그앤드롭
7. ‘왜 한 꼭짓점에서 모든 대각선을 그어야 하는가?’ 주관식 제출

## 교사 기능
- 학생의 최근 신호를 이용한 접속 중 / 페이지 이탈 / 미응답 표시
- 활동 1~7을 교사가 개별적으로 열기/잠그기
- 학생은 교사가 연 활동만 조작 가능

## 기존 프로젝트에 적용하는 순서
1. Supabase SQL Editor에서 `supabase-migration.sql` 전체를 한 번 실행합니다.
2. GitHub에서 아래 파일을 새 버전으로 교체합니다.
   - `index.html`
   - `styles.css`
   - `app.js`
   - `teacher.html`
   - `teacher.js`
3. **기존 `supabase-config.js`는 절대 덮어쓰지 마세요.** 지금 연결되어 있는 Project URL / Publishable key를 그대로 사용합니다.
4. Commit changes를 누르면 Vercel이 자동 재배포합니다.
5. 교사 페이지에서 로그인 후 활동을 열어 학생 페이지가 3초 안에 활성화되는지 확인합니다.

## 시간 표시
Supabase 원본 timestamptz는 UTC 기반으로 저장되며, 교사 페이지에서는 브라우저의 한국 시간으로 표시됩니다.
